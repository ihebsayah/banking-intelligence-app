## 1. Critical Bug Fix: `ALLOWED_COLUMNS` in `sql_builder.py`

### Problem
The SQL builder had incorrect column names for two tables:
- `branches`: referenced `branch_name` → actual column is `name`
- `risk_flags`: referenced `risk_id` → actual column is `id`

This caused silent query generation failures for any NL→SQL query involving branches or risk flags.

### Fix Applied
**File:** `services/sql_agent/sql_builder.py`
- `branches`: `['branch_name', 'region', 'city']` → `['name', 'region', 'city']`
- `risk_flags`: `['risk_id', 'flag_type', 'severity']` → `['id', 'flag_type', 'severity', 'customer_id', 'created_at']`
- Removed 4 non-existent column references across both tables

### Tests Added
**File:** `tests/test_sql_agent.py`
- `test_branch_columns_validation` — asserts `name` is in branches columns, `branch_name` is not
- `test_risk_flags_columns_validation` — asserts `id` is in risk_flags columns, `risk_id` is not
- Result: **12/12 PASS**
